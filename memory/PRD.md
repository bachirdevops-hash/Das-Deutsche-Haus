# PRD — Das Deutsche Haus
المرجع الكامل والمفصّل للمشروع موجود في: **/app/DPR.md** (تقرير المشروع الشامل — بنية، APIs، DB، أنظمة، أمان، اختبار، backlog).

## الخلاصة
موقع ثنائي اللغة (عربي RTL / ألماني LTR) لمؤسسة تعليمية: كورسات ألمانية أونلاين، Ausbildung، استشارات سفر/دراسة، وصفحة خدمات سياحية للزوار الألمان. Next.js 14 + MongoDB + Resend + Cloudinary. لوحة إدارة كاملة مع CMS وصندوق واردات موحّد بشارات رقمية وطباعة.

## قواعد حاكمة
- لا اختراع معلومات تجارية (BUSINESS INFORMATION REQUIRED عند النقص)
- كل المحتوى قابل للتحرير من الأدمن — لا hardcoded لما له محرر
- التواصل مع المالك بالعربية فقط
- الاختبار على localhost:3000 حصراً (الدومين = إنتاج قديم حتى Deploy)
- قاعدة البيانات مشتركة معاينة/إنتاج — نظّف أي بيانات اختبار
